# Lemma Agent

Supermama AI Assistant 的 Agent 與 MCP 工程專案。

## Lark MCP Server v0.1

目前提供：

- Lark App 身份驗證
- Lark Wiki URL 解析
- Lark Docx 文件讀取
- `read_lark_document` MCP Tool
- 本機 stdio MCP Server
- MCP Client 端到端測試

## 安裝

```bash
npm install
cp .env.example .env
```
