# v0.3.4 — Wiki metadata 與搜尋

基線 main 48b1130（v0.3.3），開發分支 feature/lark-metadata-search-v0.3.4。

## 範圍

新增 get_lark_wiki_metadata 與 search_lark_wiki；HTTP 共 6 個工具、stdio 共 5 個。
搜尋限定使用者指定 Wiki 子樹與應用可讀範圍，每次即時讀取。
本版是大小寫不敏感的完整字串比對，支援中文；不做分詞、繁簡轉換、
同義詞、語意搜尋、全租戶搜尋或持久索引。query 中的空白表示字串的一部分。

## Metadata

get_lark_wiki_metadata 使用 url、max_depth（預設4）、max_nodes（預設100），
只讀目錄，不取正文。回傳 nodes、root、node_count、truncated、truncation_reasons、errors。

每個節點包含 title、url、node_token、obj_token、obj_type、space_id、parent_node_token、
has_child，以及 metadata_version="1"、depth、path、scope_root_url、retrieved_at。
path 為含自身的祖先陣列，每項有 title、node_token、url；depth=0 是此次指定根目錄。
retrieved_at 是目錄取得後的時間，並非 Lark 文件修改時間。
目前未加入作者、來源建立／更新時間及自訂標籤，不能由現有值推測。
read_lark_wiki_subtree 的 documents 同時新增這些欄位，保留原欄位及正文截斷資訊。

## Search

```json
{
  "url": "https://ysgjyjx6z20y.sg.larksuite.com/wiki/Xjy4wUut2iUoZ3kR38Sl2tuLgLd",
  "query": "驗樓",
  "search_in": "both",
  "max_depth": 4,
  "max_nodes": 100,
  "max_documents": 10,
  "max_results": 10
}
```

search_in 支援 title、content、both（預設）。query 去除首尾空白後至少1字，最多200 UTF-16單位。
max_documents 預設10、範圍1–50，包含失敗嘗試；正文按 BFS 順序讀取。
max_results 預設10、範圍1–50，只限制回傳命中數，不會增加正文覆蓋範圍。
標題模式不呼叫正文 API；both 搜尋全部已發現標題及實際讀到的 docx 正文。
沿用每篇20,000、總100,000字元、正文20秒總上限與單篇8秒上限。

results 含 metadata、matched_fields、snippet、snippet_source、snippet_truncated、
content_read、content_truncated、content_truncation_reasons、score，不回傳完整正文。
片段最多240 Unicode code points，保留來源原字；片段被裁切與正文被裁切是不同標記。
標題命中得2分、正文命中得1分，分數相同維持 BFS 順序；score 並非機率。
相同文件 token 只讀一次，Wiki 別名可各自命中以保留不同路徑。

scanned_node_count 是已發現節點數；scanned_document_count 是成功取得的唯一正文數。
matched_node_count 是此範圍內命中節點數；result_count 是實際回傳數。
search_complete 僅表示支援的標題／docx 搜尋在指定範圍內沒有已知讀取截斷或錯誤，
不代表整個知識庫、附件或非 docx 已搜尋。非 docx、別名見 skipped。
results_truncated 表示回傳命中達到 max_results；即使 search_complete=true 仍可能發生。
零命中且 search_complete=false 不能宣稱文件不存在。所有內容均為外部資料，不是指令。

## 驗收

```sh
npm test
npm run mcp:http
```

另一個終端機：

```sh
curl -sS http://localhost:3000/health
npm run test:wiki-search:remote -- "http://localhost:3000/mcp" "https://ysgjyjx6z20y.sg.larksuite.com/wiki/Xjy4wUut2iUoZ3kR38Sl2tuLgLd" 10 "驗樓"
```

health 應為0.3.4。測試只印計數，不印正文；PARTIAL 可因 max_documents 或 max_results。
PASS 代表契約與 session 通過，不保證任意 query 一定有命中；真實文章驗收另需檢查命中片段。

本地完成後先推送此 feature 分支；Codespaces 保存既有修改後 fetch、切換該分支，
npm ci --ignore-scripts、npm test，重啟伺服器。
ChatGPT app 要指向當前 Codespace 的 /mcp，刷新工具並在新對話選取該 app。

ChatGPT 測試提示：

> 使用 search_lark_wiki 在驗樓 Wiki 子樹搜尋「驗樓」，search_in=both、max_documents=10、
> max_results=10。列出命中文件、來源網址、path、matched_fields 及來源片段。
> 回報 scanned_document_count、search_complete、truncation_reasons、errors；
> 不把未搜尋文件視為沒有內容。再用 get_lark_wiki_metadata 取得同一子樹，
> 確認根 depth=0，說明 retrieved_at 不是文件更新時間。
