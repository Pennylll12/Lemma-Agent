# Lark MCP Server v0.1.0

- 日期：2026-09-10
- 分支：`feature/lark-mcp-server-v0.1`
- 狀態：Local verification passed

## 版本目的

建立可重用的 Lark MCP 讀取服務，讓標準 MCP Client 能讀取公司 Lark Wiki 文件。

## Scope

### Included

- Tenant Access Token authentication
- Wiki URL 解析
- Wiki Token 轉換為 Document ID
- Docx raw content 讀取
- `read_lark_document` MCP Tool
- stdio transport
- 本機 MCP Client 測試

### Excluded

- Lark 文件搜尋
- Metadata 查詢
- MCP 寫入工具
- Official Knowledge 修改
- HTTPS remote transport
- Production deployment
- ChatGPT remote connection
